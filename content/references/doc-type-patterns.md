# 非常用文种最小结构范式（外置 · 成员遇该文种时读）

《党政机关公文处理工作条例》第八条法定文种共 **15 种**：

```
决议　决定　命令（令）　公报　公告　通告　意见　通知　通报　报告
请示　批复　议案　函　纪要
```

其中**常用 7 种**（请示 / 报告 / 通知 / 函 / 决定 / 意见 / 通报）的时态范式
由文择体在受众分析阶段给出（权威源），不在此重复；
以下为**其余 8 种**不常用法定文种的最小结构范式。

**起草时仍须有结构骨架支撑**：具体章节层次与因果权重仍按《因果备忘录》因果链映射
（文种无关骨架优先），不绑定时态细节；
时态 / 因果冲突归结构层责任方处置。

## 文种—方向—模态映射表（查表机械判定 · 模态锁定语障）

写作前先依「文种 × 行文方向」锁定模态，**全文语态锁定于该模态，禁跨模态句式混用**。

文择体据下表机械得出模态（**不增提问**），填 D-Card D1。

| 模态 | 文种（含方向条件） | 语态硬约束 | 语域特征（须与 D8 一致） |
|---|---|---|---|
| **陈述态** | 报告、纪要、公报、通报（情况类）、意见（上行供参·情况陈述部分） | 条件假设句禁入「已实施／已核实」声明域；后续安排另立「下一步工作」段并转确定性表述（「已制定××预案，将……」）；**不得出现请求句** | **沉稳纪实**：据实直陈、留有余地，不渲染、不夸张 |
| **请求态** | 请示、函（商洽／请批准）、议案、意见（上行提请审定） | 须有且仅有一个明确请求句（「妥否，请批示」「当否，请批复」「请予支持为盼」）；一事一请；事前行文 | **克制上达**：建设性建议式、谦抑陈情，不直批、不挟迫 |
| **指令态** | 命令（令）、决议、决定、通知、通报（表彰／批评类）、批复、公告、通告、意见（下行指导） | 须有祈使性引导语（「现将……通知如下」「现提出以下要求」）；批复须首句引来文 + 明确态度（同意／原则同意／不同意）；**禁止以批复代替通知下达新任务** | **权威晓谕**：明确指令、祈使引导，庄重不拖沓 |

> **方向依赖说明**：意见 / 函 / 通报为**方向依赖**，
> 须**先定行文方向再定模态**，不得一维映射。

> **覆盖自检**：本文件 8 种 + 文择体常用 7 种 = **15 种**，
> 与《条例》第八条**全覆盖无缺项**。
> 任一文种范式缺失即属 G3 取证不完备，须补齐后方可判定。

> **语域特征列的使用（D8）**
> 语域由「文种 × 方向」映射得出（上表第三列），**不预设任何具体机关、不绑定任何用户职务**；
> D8 锁定本次目标语域，辞达意落写须对齐。
>
> 下表为**可选叠加参考维度**，仅作风格提示——
> 数据务实型（重测算与可操作）／法纪刚性型（重纪律与刚性）／
> 综合协调型（重统筹与紧迫）／专业施策型（重务实与落地）；
> **参考维度不取代、不冲突上表映射**，最终以 D8 锁定值为准。

## 决议

① **会议概况与审议事项**（××会议听取并审议了××报告 / 议案）
→ ② **决议事项**（分条列项，为经表决通过的决定性意见，**用语确定**）
→ ③ **贯彻要求**（责任主体、时限）

**须经会议讨论表决通过方可行文**，
严禁以领导个人意见或未决讨论稿冒充决议；不夹请示、不含商洽语气。

## 命令（令）

① **公布 / 宣布事项背景与依据**
→ ② **核心内容**（行政法规 / 规章全文或重大强制性措施）
→ ③ **施行要求与时限**（自×年×月×日起施行）

语气庄严，不夹请示、不叙私情；**发布主体须具备法定发令权限**。

## 公报

① **事项 / 会议概况**（时间、届次、出席范围）
→ ② **主要内容与共识**（重大决定、重要成果、关键数据要点）
→ ③ **意义与要求**（可略）

用于**公开发布**重要决定或重大事项，面向社会公众，
**不涉具体执行细则、不设主送机关**。

## 公告

① **宣布由头**（依×决定 / ×事项）
→ ② **事项本体**（向国内外宣布的重要 / 法定事项）
→ ③ **结语**（特此公告）

无主送机关、不涉请示、不提执行细则。

## 通告

① **通告目的与依据**
→ ② **遵守 / 周知事项**（分条列项，可含禁止性规定）
→ ③ **执行要求与时效**（自×起施行，违者依×处理）

对象为社会公众，**语言平实可懂**。

## 批复

① **引述来文**
   （你单位《××××》（×发〔××××〕×号）收悉）
→ ② **答复意见**（同意 / 原则同意 / 不同意，**态度明确不含糊**，
   附理由与限定条件、附加要求）
→ ③ **执行要求与结语**（此复 / 请遵照执行）

**有请示才有批复**、一文一批复、针对性答复不扩大范围；
**不得以批复代替通知下达新任务**。

## 议案

① **案由**（提请审议的事项及依据）
→ ② **案据**（必要性、可行性、政策 / 法律支撑）
→ ③ **方案**（具体审议请求，**须属人大权属范围、一文一事**）

语气郑重，结语「现提请审议」。

## 纪要

① **会议基本情况**（时间 / 地点 / 主持 / 出席）
→ ② **分歧与协调**（**程序性证明功能 · E13**）
   逐方列 `主体 → 引用依据(条款) → 核心诉求 → 坚持/让步点`，
   如实反映各方曾充分陈述立场，为议定事项加装正当程序「锚」；
   回避分歧、以「两局未能达成一致」一笔带过即触发 **E13 红线**
→ ③ **议定事项**（分条，**纪实性、已决口径**；须体现对分歧的裁决依据与理由）
→ ④ **下一步要求**（责任主体 / 时限 / 例外接口，若有；**实质性义务须配 D9 例外接口条款**）

**不夹请示、不单独行文作指示、不改写未决意见为已决。**

## 附：法定公文无统计参数，但有可辨识指纹

法定公文（通知 / 请示 / 报告 / 批复 / 函）**没有**事务性材料那样的数值参数，
但仍有可辨识的写法特征：

- **承启句是文种指纹**，用错等于文种错：
  批复 / 复函用「……收悉。现批复如下：」，通知用「现将……通知如下：」。
- **表态在最前**。批复第一条就是「同意 / 不同意」，理由跟在表态之后
  ——与调研报告「先铺垫后结论」完全相反。
- **法定公文无标准篇幅**。事项说完即止；短件（500 字级）不分条。
