# 门禁取证输出契约（GATING 阶段唯一格式）

> **只在本阶段装载**：过门禁时用，平时写作阶段不读。

## 你要输出什么

你被指派了若干道门禁。**逐道给出结论，一门一行**，不要合并、不要只写总评。

```
G1 | 通过 | 证据：正文首句「……」已按 GB/T 9704 规范，无缺项
G4 | 退回 | 原因：第 3 段出现「赋能抓手」等 AI 味表述 | 证据：正文第 3 段
```

## 三段分别是什么

| 段 | 写什么 | 能省略吗 |
|---|---|---|
| 门禁号 | `G1` 到 `G13` 中的编号，照指派抄 | **不能** |
| 结论 | `通过` 或 `退回`。**只有这两个词** | **不能** |
| 证据 | 你据以判断的**正文原句或具体位置** | **不能** |
| 原因 | 只在 `退回` 时写，说清缺什么 | 通过时省略 |

## 五条铁律

1. **一门一行，行行带门禁号。** 漏掉某道 = 该门禁无证据。
   程序按「你交了几道」核对，缺席即判无证据——不是判通过，是判「没查」。

2. **证据必须是可定位的原句。**
   「已核对全文，格式合规」这种**不算证据**——它无法被复核，等于没查。
   要写你实际看到的那一句，或它在第几段。

3. **没查就说没查，别猜。**
   需要外部依据（政策原文、法规）而手上没有的，把结论写 `退回`，
   原因写「缺 XX 依据」，**不要**凭印象给一个看似合理的通过。

4. **不写门禁没给你的内容。**
   只对你被指派的门禁作答。派给你 G1/G2 就只答这两道。

5. **先答格式，再答内容。**
   结论行必须在最前面，正文引用在证据段——
   复核时先看结论对不对，再看依据是什么。

## 判读方式

程序只认这一种格式：`门禁号 | 结论 | 证据：…`。

写得漂亮但格式不对，等于没交。
