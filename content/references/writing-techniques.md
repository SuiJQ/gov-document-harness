# 公文写作技法库

语言层与结构层的写作依据。辞达意负责语言层，陈纲举负责结构层。

> **样本量差异**：调研报告、领导讲话参数可信；工作意见、经验材料尚可；
> 工作方案、经验总结样本偏薄，参数仅供参考。
> **参数区间是描述性的，不是规范性的**——
> 语料个体差异极大，自检只判硬冲突，**不拿均值当合格线**。
> **好文章不整齐，整齐的往往是平庸作品。**

---

## 一、公文语言四大原则

**准确 · 平实 · 简明 · 庄重**

### 1. 准确（第一要求）

用词准确、造句准确、表意准确。

**句子成分要完整**
汉语单句有主、谓、宾、定、状、补六种成分。
公文写作中成分须适当、合理，**不能任意省略和无故残缺**。

| 差 | 好 |
|---|---|
| 通过学习，使全体干部提高了认识。（缺主语） | 通过学习，全体干部提高了认识。 |

### 2. 平实

朴实无华、语意实在，**不堆砌辞藻，不溢美，不虚饰**。

- 少用形容词、副词，**多用名词、动词**，表述具体行动和事实
- 不使用「极其」「非常」「特别」等程度副词
- 不使用「辉煌」「卓越」「巨大」等夸张词语
- **数据说话**：用具体数据说明工作成效

### 3. 简明

开门见山、删繁就简、多用短句。

| 差 | 好 |
|---|---|
| 为了使本次会议精神得到全面贯彻落实，切实推动各项工作有效开展，经研究决定，特制定本实施方案。 | 为贯彻本次会议精神，推动工作落实，特制定本方案。 |

具体方法：

1. **开门见山**——开头直接点明主题
2. **删繁就简**——删「的」「了」「进行」等虚化词
3. **使用短句**——每句只表达一个完整意思
4. **词语精准**——用一个词表意清楚，不用一串词
   （用「已」不用「已经」，用「拟」不用「打算」，用「即日」不用「从即日起」）

### 4. 庄重

使用规范的书面语言；不用方言、土语、网络语言、口语、俗语。

| 差 | 好 |
|---|---|
| 这事儿得好好琢磨琢磨，不能拍脑袋决策。 | 此事需认真研究，慎重决策。 |

**稳妥用词，避免绝对化表态、留有余地**：

| 用 | 不用 |
|---|---|
| 应予肯定 | 就是好 |
| 基本符合 | 完全符合（未完全核实前） |
| 原则同意 | 完全同意（需补充完善时） |
| 拟同意 | 同意（未经最终决定时） |

## 二、常见用词错误速查

### 口语化 → 规范

| 错误 | 正确 |
|---|---|
| 老百姓 | 市民、群众、居民 |
| 一把手 | 主要负责人、主管领导 |
| 打算 | 决定、拟定、计划 |
| 没有着落 | 缺口、存在困难 |
| 要求（对上级） | 拟请、恳请、建议 |
| 一把手抓 | 主要领导亲自抓 |
| 一通到底 | 一抓到底、落实到位 |
| 狠抓 | 强化、加强、加大力度 |

### 数字与时间

| 错误 | 正确 |
|---|---|
| 截止 2014 年 10 月 30 日 | 截至 2014 年 10 月 30 日 |
| 上世纪八十年代以来 | 20 世纪 80 年代以来 |
| 二〇〇六年 | 2006 年 |

### 成语误用

| 词 | 误用 | 正解 |
|---|---|---|
| 明火执仗 | 指抢劫等 | 公开、公然 |
| 首当其冲 | 误用为「首先」 | 比喻最先受到攻击或遭遇伤害 |
| 差强人意 | 误用为「不满意」 | 大体上还能使人满意 |
| 鼎力相助 | 感谢别人帮助 | 用于请托或感谢，**不能用于自己帮助人** |
| 叹为观止 | 形容事物好到极点 | **不能用于负面事物** |

## 四、标题拟定「六看」

1. **看是否准确恰当**——题文相符，宽窄适度；杜绝题不对文、文不对题
2. **看是否明确集中**——越单一、越集中越好
3. **看是否照应总题**——小标题与总标题相互领属、呼应配合
4. **看是否合乎逻辑**——总标题与小标题为领属关系；小标题相互间为并列关系，
   **同层次内容不可跨类**
5. **看是否具有艺术性**——准确明确的前提下生动、有新意
6. **看是否匀称和谐**——句式、字数整齐协调

### 三个注重

| 注重 | 要点 |
|---|---|
| **积累** | 从报刊、公文材料中收集好标题，建立素材库并分类整理 |
| **模仿** | 有合适的可改头换面后使用（**须自行重写，不可照抄**） |
| **实践** | 先定标题再写内容；边写边改；写完再次打磨 |

### 技法与字数参数

| 文体 | 首选技法 | 避免 |
|---|---|---|
| **法定公文篇名** | **素朴陈述**（发文机关+事由+文种） | **全部技法** |
| 事务材料篇名（调研/汇报/总结） | 素朴陈述 或 引号概念化 | 喻体、条件递进 |
| 公文一级标题（**分析类**） | 双分句（动作+目的） | 喻体、对照结构 |
| 公文一级标题（**业务类**） | 素朴陈述 | 全部技法 |
| 党建族材料 | 严格对仗 + 成效动词 | 条件递进、对照结构 |

| 文体 | 标题字数 |
|---|---|
| 党建族材料 | 16-17 字 |
| 公文篇名 | 17 字 |
| 公文一级标题（**分析类**：调研 / 讲话 / 经验） | **17-18 字** |
| 公文一级标题（**业务类**：方案 / 意见） | **4-8 字** |

> 业务类与分析类一级标题字数**相差 4 倍**。
> 这个差异比技法选择更影响「像不像」。

### 成组标题必须同构

一组一级标题**不可混用技法**——
要么全数字式，要么全设问式，要么全动宾式。

### 两条硬纪律

- **篇名不加修辞前缀。**
  不要写「从 X 说起：做法和启示」「把 X 办成 Y——做法和启示」这类
  在正式标题前加一句叙事钩子或比喻短语的格式——
  **那是新媒体和自媒体的写法，不是公文的写法。**
  篇名直接说事：「XX 的做法和启示」「关于 XX 情况的调研报告」「在 XX 会议上的讲话」。
- **喻体**（压舱石 / 组合拳 / 生命线）用在篇名或讲话稿标题，
  **别用在一级标题**（语料使用率仅 1%）。

## 五、经验提炼四步法

| 步 | 做法 |
|---|---|
| **1. 罗列工作、整理分类** | 列出所有工作内容（不分大小），按性质 / 成效 / 时间分类 |
| **2. 归纳亮点、提炼主题** | 找创新、有影响力、有成效的工作，提炼关键词与特色表述 |
| **3. 划分层次、打磨标题** | 划分逻辑层次、拟定标题、检查层次间逻辑关系 |
| **4. 严谨行文、反复修改** | 文字精练、标题盖住内容、逻辑层次清楚 |

**层次划分**：各层次之间不交叉、不重复，遵循 MECE 原则（相互独立、完全穷尽）。

## 六、文种骨架公式（结构层 · 陈纲举用）

| 文种 | 骨架公式 | 重心段占比 | 段内主力标记 |
|---|---|---|---|
| 工作方案 | `[依据] → [意义/要求] → [任务] → [步骤] → [保障]` | 任务 **38-67%** | `1.` `2.` + 年份，**无「一是」** |
| 工作意见 | `[依据] → [总体要求] → [重点任务] → [保障措施]` | 任务 **44-53%** | `（一）` + 「要」字排比，**无「一是」** |
| 调研报告 | `[缘起] → [做法成效] → [问题原因] → [建议]` | 三段均分 23-38% | `（一）` + 口语命名问题 |
| 调研报告（乙组） | `[缘起] → [问题表现] → [原因] → [对策]` | 对策 23-39% | 「一是二是」+ 加引号自造概念 |
| 经验材料 | `[背景] → [做法分述] → [启示]` | 做法 **47-59%** | 「一是二是」（**最密**） |
| 领导讲话 | `[称谓议程] → [为什么] → [做什么] → [谁来干]` | 恒 3 段，各 18-45% | 设问 + 俗语 + 二次称谓 |
| 经验总结 | `[总体成效] → [环节一/二/三]` | 三段等分 23-43% | 「一是二是」+ 绝对值数据 |

### 三条跨文种规律

1. **重心分布分两族**
   - **单段独大型**（工作方案、工作意见、经验材料）把重量压在「做什么」
   - **均衡型**（调研报告、经验总结、领导讲话）各功能段近乎等重

   > **误把调研报告写成单段独大，等于写成了经验材料。**

2. **段内标记与文种强相关，可反向校验**
   工作方案、工作意见的「一是」计数**全部为 0**；
   经验总结、经验材料最密。

3. **过渡强度按文种递减**
   领导讲话用显式口语过渡 → 调研报告 / 经验材料把转折句与成效句放在新段段首
   → 工作方案与工作意见完全无过渡句。

   > **越是规范性文件越不需要过渡，越要说服人的文体过渡越显性。**

## 七、千字级党建经验材料（另一套参数）

**判族规则**（判错这一步，后面全错）：

```
1000 字左右的党建 / 基层经验、信息、简报   → 党建族
正式发文，或 2500 字以上的材料            → 公文族 → 再判文种
```

**两族参数互斥**：篇幅与一级标题上**不重叠**，判族只看这两项。

> **千字材料加一级标题就变成了压缩版公文。**

### 党建族参数

| 项 | 数值 |
|---|---|
| 字数 | 1,000-1,200（中位 1,119） |
| 段落数 | **6 段**（导语 1 + 做法 3-4 + 收尾 1） |
| 段落长度 | 156 字 |
| 平均句长 | 51 |
| 一级标题 | **0** |
| 「一是二是」 | 0.77（**90% 篇目为 0**） |
| 顿号 | 23.7‰ |
| 要求词 | **2.30‰**（**只有公文族的 1/3**，陈述做法不下指令） |
| 长引语 | **2.9‰**（引群众原话，这一族的正向指纹） |
| 百分比 | 0.35‰ |

### 千字级的核心手法

> **把一级标题写成段首句。**
> 标题的**功能**（预告本段做什么）保留，**形式**（编号 + 独占一行）取消。

段首提领句与独立小标题两种排版形态，二者**是同一功能的两种形态**：

```
强化思想引领，校准干事创业"总开关"。
深耕主责主业，筑牢能源保供"压舱石"。
厚植为民情怀，画好凝心聚力"同心圆"。
严明纪律作风，织密稳健发展"防护网"。
```

提领句中位 14 字，与公文一级标题的 13-17 字**同一量级**。

### 千字级材料的三条硬规则

| 规则 | 说明 |
|---|---|
| **绝不写自身遗留问题** | 语料 **0/77 篇**提及本单位尚未解决的不足。问题必须以「已被我解决」的形态出现（81% 篇目写问题） |
| **问题只写已解决的** | 可写「曾面临……难题」，因为帽子在文中被摘掉了 |
| **归因优先给机制** | 机制是**唯一可被他人复制**的归因对象（覆盖 83-86%） |

> **注意边界**：「自陈我们曾是后进」的摘帽叙事**只在本单位写自己时成立**；
> 由外人指名某单位是后进属负面定性，**不可照搬**。

### 千字级与长篇级的结构分野

| 维度 | 3500 字级 | 千字级 |
|---|---|---|
| **做法段占比** | 47-59% | **76.8%** |
| **分层装置** | 三层（`一、`＋`（一）`＋段内`一是`） | **一层**（段首提领句），25% 无分层 |
| **「一是」密度** | 14/12 个每篇 | **90% 篇目为 0** |
| **启示段** | **必带** | 仅 13% 末段做规律提炼 |
| **成效** | 独立成段 | **不独立成段**，是每条做法的收口句 |
| **导语** | 政治锚定 + 背景 | **不做政治锚定**：仅 3% 引中央文件 |

### 做法陈述的组织方式

**并列铺陈，不是分层递进。**
做法段之间几乎不用连接词：**362 个做法段中，仅 2 段（1%）
以「同时／此外／一方面」等连接词起首。**
连提领句之间的逻辑关系都不交代，**纯并列**——
读者靠提领句的**句式同构**感知平级。

五条提领句同构到近乎公式的写法：

```
组织强基：筑牢产业发展的"主心骨"。
链上共建：激活产业集群"强磁场"。
党建赋能：布局未来产业。
开放协同：深化海外布局。
文化聚力：夯实企业发展"向心力"。
```

**四字短语＋冒号＋动词短语**：
前四字是做法命名，后半是效果隐喻。

**「一是二是」在千字材料里近乎废弃。**

| 标记 | 出现次数 | 覆盖篇数 |
|---|---|---|
| 一是／二是 | 59 | **8 篇（10%）** |
| （一）（二） | 18 | 2 篇 |
| 一、二、（一级标题） | 3 | 1 篇 |
| 首先／其次 | 4 | 2 篇 |
| 第一／第二 | 0 | 0 |

> **这里要修正一处判读。**「一是二是 0.77 次/篇」这个平均值掩盖了实际分布——
> 它是**极度集中而非均匀摊薄**：
> **69 篇（90%）一次都不用**，
> 用的 8 篇里两篇是会议纪实和理论文章（非经验材料），一篇是学术论文体。
> **真正的千字经验材料用「一是二是」的只有 5-6 篇。**

### 成效呈现方式

| 手段 | 出现次数 | 覆盖篇数 |
|---|---|---|
| **群众／职工评价引语**（引号内≥8字） | 335 | **70 篇（91%）** |
| 绝对值数据（数字＋单位） | 346 | 50 篇（65%） |
| 获奖／称号／上级肯定 | 55 | 26 篇（34%） |
| 相对比较（同比／增长／提升至） | 36 | 23 篇（30%） |
| 百分比 | 35 | 22 篇（29%） |
| 经验被推广／媒体报道 | 19 | 10 篇（13%） |

**28 篇（36%）完全没有任何量化数据。**

> **千字材料证明「我做得好」的主力不是数据，是引语和机制的完整度**（推断）。
> 数据要占篇幅，1100 字里塞不下多组数据；
> 而**一句引语 30 字就能提供可信度**。

### 长引号引语引谁的话（191 处／覆盖 61 篇）

| 说话人类型 | 出现次数 | 覆盖篇数 |
|---|---|---|
| **基层干部／党员／书记** | **45** | 23 篇 |
| 群众／居民／村民／职工 | 26 | 16 篇 |
| 具名个人（姓名＋说） | 15 | 7 篇 |
| 专家／学者／研究员 | 4 | 2 篇 |

**干部引语（45 次）多于群众引语（26 次）。**
**引干部话更多，且两者功能不同**：

- **干部引语提炼规律**——
  「伏季休渔是渔民转产转型的黄金期，依托海上党支部，
  推动渔民从靠海吃饭转向一技多能，真正实现休渔不休收、上岸有奔头。」
- **群众引语验证效果**——同篇一位渔民的口述印证上句结论。

## 八、语言层执行清单

```
□ 平均句长 45-55 字（不要写成 25 字的口语句）
□ 长句（≥50 字）占比 40-48%
□ 短句（≤15 字）占比 10-16%，且用在发力处
□ 顿号密度 ≥ 每千字 12 个（体现并列枚举）
□「必须 / 应当」全篇 ≤5 处
□ 主体语气用「要 + 动词」
□「进一步」可用，但全篇 ≤3 次
□ 段内分层用「一是 / 二是 / 三是」
□ 无法核实的数据留占位，不编造
□ 层级深度匹配篇幅
```

### 句长的技术来源：并列成分堆叠

```
写「A 是 B」就停              → 句长 42、顿号疏 → 读起来不像公文
写「A 是 B，三者在 X、Y、Z 上高度重叠」 → 句长 51、顿号密 → 有公文质感
```

**四种堆法**（一句话里常同时用两三种）：

| 堆法 | 例 |
|---|---|
| **事项并列** | 把「这件事」换成「这几件事」 |
| **主体 / 责任并列** | 「镇干部包村、村干部包组、党员包户」 |
| **条件并列** | 「工序清晰、判定标准明确、数据可采的环节」 |
| **收口** | 末尾挂一句效果或底线（确保……/ 不留死角 / 一天都不能含糊） |

### 并列过度与不足按文种分两侧

```
分析类、叙事类（调研报告 / 领导讲话 / 经验材料 / 经验总结 / 党建族）
    → 容易并列不足，要补
规范性文件（工作意见 / 工作方案）
    → 容易并列过度，要砍
```

> **反直觉的一条**：砍顿号**会让句长上升**——
> 因为拆并列用的是**分句不是句号**。

### 先判自己偏哪一侧（诊断法）

八篇初稿的实测：**六篇同时出现「句长偏短 + 顿号偏疏 + 要求词偏少」**
（调研报告 40.2 字／13.5‰／9 个，经验材料 38.4／12.4‰／7，
领导讲话句长 32.0），
另外两篇恰好相反，且**都是规范性文件**
（工作意见顿号 38.5‰ 对区间 25-31，工作方案顿号 32.4‰ 对区间 14-22）。

> **三项指标同向偏移 = 系统性偏了一侧**，不是随机波动。
> 反之若三项互相打架，多半是逐句硬凑出来的，**比整体偏移更麻烦**。
>
> **先判偏哪一侧，再决定补还是砍**——
> 盲目把每句都加长，是把一侧问题换成另一侧。

### 不该堆的地方

| 不可堆 | 原因 |
|---|---|
| **引语** | 引语本来就短，为拉句长去改引语，等于把最实的部分改虚 |
| **场面** | 场面靠短句和白描，一堆并列进去就没了 |
| **引号概念** | 不能为凑密度硬造，否则材料会写空 |
| **规范性文件的约束条款** | 每条都带四五项并列，全篇顿号必然顶破 |

### 强制词配额怎么砍

「不得」「严禁」与「必须」「应当」**共用同一个配额**。
写规范性文件时每提一条约束就顺手写「不得」，很容易一路堆到七八个。

| 原写法 | 改后 |
|---|---|
| ××**不得**下派 | ××**一律取消** |
| ××**不得**随意抽调 | ××**不能**随意抽调 |
| **不得**违规使用编外人员 | 违规使用编外人员的，要**一并纠正** |

语气一点不弱，配额也不破。

## 九、站位铁律（认知层）

### 1. 不把制度缺陷当切入点

统计口径 226 篇中，以**制度缺陷作为开篇切入点的仅 2 篇**。
制度问题一律出现在「成绩—问题—原因」链条的**原因位**，
**前面必须先垫战略高度和已有成效**。

> **想批评，先把资格挣到手。**

### 2. 力度词由权力关系决定，不由礼貌决定

| 词 | 用法 |
|---|---|
| **「建议」** | **上行文专属**（调研报告 2.5–3.2，工作意见 0.2）——**有权决定的人不「建议」** |
| **「希望」** | **下行且面向不可命令对象时的唯一选项**（讲话 4.4，其余 ≤0.4）——**乡镇不是他的下属** |
| **「严禁 / 不得」** | **只出现在工作意见**（真规范性文件） |
| **「必须」** | 常指向**不可回避的客观前提**，不是作者在下命令 |

### 3. 成绩外部化、问题两分法

**成绩**一律外部化、上溯化，句式固定「在……领导 / 支持下」。

**问题**走两条路：

| 路线 | 做法 | 例 |
|---|---|---|
| **客观化** | 归给历史、地理、发展阶段、外部环境，**不含责任主体** | 「由于历史和地理的原因……」 |
| **主观化** | 归给思想作风，**但必须加「个别 / 部分 / 少数」限定** | 「主要原因在于**一些**党员干部……」 |

> **关键规律**：凡标「根本原因」者几乎必落在**思想认识**上。
> 思想问题可通过教育自我纠正，属本级能承诺的范围；
> **把根本原因定位在思想上，等于把整改责任收进自己能兑现的边界。**

### 4. 敏感议题的六种处理技巧

| # | 技巧 |
|---|---|
| 1 | **部门冲突**＝双方具名 + 归因于技术分歧 + 用「推测」降级指控 |
| 2 | **把批评抽象成通例**——无主语、无地名，讲的是现象规律 |
| 3 | **最重的判断挂在他人名下**——「被媒体称为……」 |
| 4 | **预先申领最高授权，并主动自设边界**——批评与自证同步 |
| 5 | **靠典故位移批评对象**——把重话锚定在历史或典故上 |
| 6 | **先自我归责，再向下要求**——自己认领后才说「同志们要……」 |

### 5. 案例具名规则（边界极分明）

| 情形 | 具名规则 |
|---|---|
| **正面经验 / 技术方案** | **全具名**（地名 + 单位 + 项目 + 金额），因为要可复制 |
| **已公开处理的负面典型** | **全具名**，句式「**原** + 职务 + 姓名 + 事件名」——**已免职、已有公开定性的，才敢指名** |
| **在办 / 未公开的问题** | 单位具名到处室 + 人名「某某」+ **金额精确**——可核查性留在数字上，风险从姓名和单位上卸掉 |
| **普通群众 / 信访人** | 匿名保护 |
| **批评同级或上级** | 模糊主语：「一些地方 / 有的单位 / 个别干部」 |

> **没有中间态**——不存在「某市某局长贪腐严重」这种既不具名又无数字的写法。

### 6. 不越权承诺

「建议」的最弱形态只请求启动程序。
**跨部门事项不替对方拍板。**

## 十、反面清单：这些优秀公文没有做什么

**均为可核验的统计或抽样陈述**，不是个人偏好。
可作为 G4 / G7 的反向自查项。

1. **不用空洞表态开篇。** 226 篇中前 45 字含「高度重视」的仅 **4 篇**，
   全是经验材料，且都不是表态而是历史陈述（立刻接具体年份和文件名）。
   **76 篇调研报告中没有一篇以「高度重视」起句。**

2. **不用空动词充数。** 「狠抓落实」全库 16 次（0.1 次/篇），「狠下功夫」6 次。
   「进一步」2.5 次/篇、「切实」2.0 次/篇虽常见，
   但后面基本都跟具体动作，**不作独立主张**。

3. **不把制度缺陷当切入点**（226 篇仅 2 篇）。想批体制，先垫战略与成效。

4. **不在建议段堆数字，也不在成效段回避数字。**
   末 10% 占 2%、前 20% 占 28%，是**职能分工而非均匀撒点**。

5. **不用无主语空排比撑问题段。** 抽样 76 篇调研报告中，
   无一篇问题段只有四字排比而无案例或数字。

6. **不省略调研方法。** 凡称「调研报告」者基本交代时间、地点、样本、方式，
   方式常列 4-5 种。

7. **上行文不在结尾堆谦辞。** 「妥否请批示」0 次、「请审阅」0 次、
   「特此报告」2/226 篇。

8. **不在批评时既指名又不留证据链。** 具名负面案例必带「原」字或出自公开报道；
   未公开的一律「某某」但金额精确。**没有中间态。**

9. **不越权承诺。** 「建议」的最弱形态只请求启动程序，
   跨部门事项不替对方拍板。

10. **经验材料不用转折。** 经验总结转折 0.0 次/篇、含百分比 0/8 篇。
    推断：经验材料的任务是**可复制的做法**而非平衡评价，
    混入「但是」反削弱示范性。

11. **不把成绩归给自己。** 成绩句式一律「在…领导/支持下」；
    抽样中未见「我们创造性地开创了…」这类自我归功，
    自评词多是「初步」「积极成效」「明显好转」。

12. **不对非下属用命令式。** 对市县用「要」、对乡镇用「希望你们」；
    工作意见「希望」0.0 次/篇、讲话 4.4 次/篇——
    **用词由权力关系决定，不由礼貌决定。**

## 十一、数据纪律

### 可以不用数字

**真实公文 51%–100% 完全不用百分比。**

> 下表为**分文种**口径；`references/stats-baseline.md` 另有**按甲乙两组**的
> 统一口径（60-72%）。两者切分方式不同，**不是矛盾**，引用时注明口径即可。

| 文种 | 零百分比篇数占比 |
|---|---|
| 经验总结 | **100%** |
| 工作方案 | 80% |
| 领导讲话 | 75% |
| 工作意见 | 64% |
| 经验材料 | 59% |
| 调研报告 | 51% |

> **结论：不掌握真实数据时不要编造——**
> **靠逻辑深度和判断力撑起文章，这是语料证明可行的路径。**

### 数据的职能分工

- **成效 / 情况段**：数据密集，用来奠定「我摸清了情况」的**资格**
- **建议段**：**不摆数据**——建议是**主张**而非事实

> 数据在前半篇密集，后 20% 几乎无数据。
> 这是**职能分工而非均匀撒点**。

### 四种最有效的数据句式

| # | 句式 | 例 |
|---|---|---|
| 1 | **落差对照** | 支持率 90%，但参与率不及一半，投放准确率更是打对折 |
| 2 | **绝对数 + 相对数 + 比率三件套** | 农村小学 X 所，占全国 Y%，在校生 Z 万人，占 W% |
| 3 | **城乡 / 内外双向对比** | 农村人均年培训 2.6 次，城市 5.2 次 |
| 4 | **宏观数据折算到个体体感** | 一个三口之家一年产生约 1 吨垃圾 |

**易被忽略的第五类：方法学数据**——
「对 X 个处室、Y 间办公用房、Z 名干部进行了调查走访」。
**样本量和方法数写清楚，结论自带信度。**

### 引用密度

**引用密度反映论证需求，不反映政治正确程度。**

- 基层党建经验材料 77 篇中仅 2 次高层引用，其中 1 次还是课程名称
- **不必为显得政治正确强行引用**
- 要论证某个观点时才需要引用，与政治态度无关

## 十一、占位符纪律（最高数据纪律）

**严禁编造。** 未知信息必须向用户询问或使用统一样式的占位符，
**不得自行填充貌似合理的内容**。

只用以下三种占位写法，**除此三种不用其他占位写法**：

```
【待补：xx】      缺失的数字 / 文号 / 人名 / 日期，须由用户补齐后方可定稿
【示意·待核】     为帮助体感给出的参考量级，使用前必须核实替换
【待核对原文】    引用重要论述、上级文件表述拿不准时
```

> **宁可占位，绝不杜撰。**

**导出前必须扫描残留占位符；存在未处理占位符时禁止导出，并列出待补信息。**

## 十二、方法论纪律

### 两条

1. **参数解决「像不像」，不解决「对不对」。**
   内容是否站得住、判断是否准确、政治表述是否得体，**参数管不了**。
2. **不要把稿子往中位数上拽。**
   迭代时若发现自己在做「补字数、拉句长、调顿号密度」这类动作，**停下来**——
   代价是把场面和短句挤出去。

> **好文章不整齐，整齐的往往是平庸作品。**

### 偏离时怎么办

- 只有**硬冲突必须改**；
- **软提示要先问一句**「我这一项偏离是因为写进了什么东西」，
  答得出来就留着，并**在稿件说明里写清是有意偏离**。
- **不得默默放过。**

### 五种最有效的数据句式之外，还要写「场面」

好的公文里会有**具体场面**——不是概括，是能画出画面的细节：

- **具体场面**：能让人在脑子里看见的细节
- **人有名字、有原话**：人物不是「一位群众」，引语不是转述
- **比喻**：用比喻把抽象的工作说法落地
- **敢写难听的**：直接摆问题、干部原话、带数字的具体案例
- **留一个没解决的**：不是每篇都要收得圆满
