# 参数卡 · 按文体查数值

> **最快自检入口**：写作前定位到你那一行，按数值执行。
> 数据来源：真实公文 **229 篇** + 党建千字经验材料 **77 篇**，全量统计。
> 详细推导见 `references/stats-baseline.md` 与 `references/language-dna.md`。

> ### 三条使用纪律
> 1. **区间外不等于错。** 自检只判**硬冲突**，区间仅作对照。
>    语料里最有质感的几篇往往多项落在框外；
>    为了消掉提示把稿子改成最匀速的样子，是本包明确反对的做法。
> 2. **中位数不是合格线。** 同文种内部差异往往大于文种之间的差异。
>    均值会被少数长文拉高，照均值写反而会被判偏离。
> 3. **参数解决「像不像」，不解决「对不对」。**

## 第一步：先判文体族（判错这一步，后面全错）

两个文体族的参数**互斥**，不是「有差异」：

| 文体族 | 篇幅 | 句长 | 一级标题 | 一是二是 | 引号概念‰ | 长引语‰ |
|--------|------|------|---------|---------|----------|--------|
| **党建族** | 1,119 | 51 | **0.04** | 0.77 | 10.7 | **2.9** |
| **公文族** | 2,500-3,700 | 53-64 | 2-5 | 1-9 | 0.9-17.1 | — |

**判族规则**：

```
1000 字左右的党建/基层经验、信息、简报    → 党建族
正式发文，或 2500 字以上的材料            → 公文族 → 再判文种
```

> **千字材料加一级标题就变成了压缩版公文。**
> 两族在**篇幅和一级标题**上不重叠，判族只看这两项。

**法定公文按公文族的对应文种行取值**（通知/请示/报告等在本语料中样本偏少），
版式与结语依 `references/doc-type-patterns.md` 与 GB/T 9704 体系。

> 顿号为每千字个数（‰）；其余为每篇个数。
> **加粗** = 该列极值，是这个文种最具辨识度的参数。
> **样本量警示**：工作方案(10)、经验总结(8) 样本偏薄，参数仅供参考。

**为什么用中位数而不是均值。**
这批语料的个体离散度极大，同一文种内部的差异往往大于文种之间的差异
（调研报告的「一是二是」从 0 到 20 次都有；
领导讲话六篇的句长标准差从 21.8 到 44.3）。
均值会被少数长文拉高——调研报告字数均值 4,406、中位 3,492，
**照均值写反而会被自检判偏离 p75**。
中位数加四分位描述的是「多数作品落在哪里」，
均值描述的是一个并不存在的平均作品。

## 力度词配额换算（按篇计算，方便直接用）

以各文种**中位字数**计算的每篇实际个数：

| 文种 | 强制词（必须/应当/不得） | 要求词（要/切实/确保） | 建议词 |
|------|----------------------|-------------------|--------|
| 调研报告(3492字) | **1-2 个** | 26 个 | 6 个 |
| 领导讲话(3700字) | **2-3 个** | **47 个** | 3 个 |
| 工作意见(3300字) | **2 个** | 40 个 | 1-2 个 |
| 经验材料(3600字) | **1-2 个** | 20 个 | 3-4 个 |
| 工作方案(3600字) | **2 个** | 22 个 | 6 个 |
| 经验总结(2500字) | **0 个** | 14 个 | 0-1 个 |
| 短经验材料(1119字) | **0 个** | 2-3 个 | 0 个 |

**「必须/应当」是稀缺资源**：全语料密度 0.10-0.96‰，
一篇文章通常只有 **0-4 个**。用多了就失效。

**降低密度的手法**（语气不弱，配额不破）：

| 原写法 | 改后 |
|---|---|
| ××**不得**下派 | ××**一律取消** |
| ××**不得**随意抽调 | ××**不能**随意抽调 |
| **不得**违规使用编外人员 | 违规使用编外人员的，要**一并纠正** |

## 数据密度：可以不用数字

| 文种 | 零百分比篇数占比 |
|------|----------------|
| 经验总结 | **100%** |
| 工作方案 | 80% |
| 领导讲话 | 75% |
| 工作意见 | 64% |
| 经验材料 | 59% |
| 调研报告 | 51% |

**结论：51%-100% 的真实公文完全不用百分比。**
不掌握真实数据时，**不要编造**——靠逻辑深度和判断力撑起文章，
这是语料证明可行的路径（D-034）。

需要用数据时，每篇 **0-4 个百分比**即可（调研报告 3.8 个为最高）。

## 标题字数（按用途）

| 用途 | 字数 |
|------|------|
| 党建族标题 | 16-17 |
| 公文篇名 | 17 |
| 一级标题·**分析类**（调研/讲话/经验） | **17-18** |
| 一级标题·**业务类**（方案/意见） | **4-8** |

## 收尾模式（229 篇全量）

| 模式 | 甲组 | 乙组 |
|------|--------|--------|
| **自然收束（无程式化结语）** | **87%** | **75%** |
| 号召/展望 | 2% | 11% |
| 总结升华 | 7% | 3% |
| 建议/期望 | 1% | 7% |
| 程式化结语（请遵照执行等） | <2% | <2% |

**75-87% 是自然收束。** 调研报告 / 经验材料**不要**加程式化结语。

**法定公文仍需程式化结语**（本语料样本不足，按行文方向选）：

```
上行请示  →  以上请示，请予批准 / 妥否，请批示
上行报告  →  特此报告 / 以上报告，请审阅
下行通知  →  请遵照执行 / 特此通知
平行函    →  专此函达，请予复函 / 特此函复
讲话稿    →  号召 + 表决心（11% 用此式）
```

> **两条口径并存不矛盾**：
> 统计口径针对**材料类**公文；法定文种的结语由惯例与规范体系规定。
> 适用范围不同，**不得混用**。

## 开头策略分布（229 篇全量，无单一主导）

| 策略 | 甲组 | 乙组 |
|------|--------|--------|
| 时间/背景式 | 16% | 7% |
| 引领导讲话式 | 12% | 2% |
| 判断/立论式 | 9% | 10% |
| 目的式（为…） | 8% | 13% |
| 政治锚定式 | 7% | 6% |
| 依据式（根据/按照） | **6%** | 8% |
| 金句破题式 | 4% | 1% |
| 其他/个性化 | 18% | 49% |

**最高占比仅 16%，「依据式」只占 6-8%。**
优秀公文**不倚重程式化开头**——这直接反驳「公文开头都是套话」的印象。

**站位选择铁律**（认知层 226 篇）：制度缺陷作为开篇切入点**仅 2 篇**。
批评体制前必须先垫战略高度和已有成效——
**想批评，先把资格挣到手。**

## 引用密度：反映论证需求，不反映政治正确

77 篇党建千字经验材料里，高层引用只出现 **2 次**，
其中 1 次还是课程名称，真引用仅 1 篇。
**基层单位写自己做成的事，不需要借最高权威背书。**

> **不必为「显得政治正确」强行引用。**
> 要论证某个观点时才需要引用，这是**论证需求，与政治态度无关**。

## 快速自检清单

```
□ 文体族判对了吗？（党建族/公文族，参数互斥，只看篇幅和一级标题）
□ 字数落在该文种区间了吗？
□ 身份证参数对吗？（查上表「身份证参数」）
□ 一是二是的次数对吗？（工作意见 1 vs 调研报告 9，差 9 倍）
□ 三级标题用对了吗？（只有工作方案该有 11 个，讲话/总结应为 0）
□ 强制词是否超配额？（多数文种只该有 0-2 个）
□ 顿号密度对吗？（按文种查上表，全文种落在 14-31‰；明显低于本文种 p25 说明并列结构不足）
□ 有没有编数据？（51-100% 真实公文零百分比，宁可不用）
□ 收尾有没有多加程式化结语？（75-87% 是自然收束）
□ 标题字数对吗？（业务类 4-8 字 vs 分析类 17-18 字）
```
