# 行政主体排序规则库（外置 · 遇多主体并列枚举时读）

公文多主体并列时，排列顺序承载**职权归口、牵头主责、政治位阶、党内序列**等刚性规则，
**不可按训练语感或词频共现排列**。

本库为场景化规则库，覆盖通用行政场景与**党内法规口径**；
凡正文枚举 ≥3 个并列行政主体，须**先查本库定场景与序列**，
再落写并**随附 1 行排序依据**。

## 通则

1. **排序须可举证**
   凡枚举 ≥3 个并列主体，必随附 1 行排序依据
   （如「应急管理部门综合协调牵头、消防救援主战、住建行业主管、卫健医疗保障」）；
   **无依据即 G2 硬退回**（E8）。
2. **同一序列内不得混用两套排序依据**；跨序列切换须显式说明。
3. **「等」字仅用于确有省略**，
   **不得用「等」掩盖排序依据缺失或漏列关键主体**。
4. **领导同志排名硬停车**
   凡涉及领导同志并列排名且序列不确定，一律**升提问硬停车，禁止按语感推断**
   （政治风险等级最高）。

## 场景 1　应急 / 联合处置

```
牵头（综合协调主管部门）
  → 主战（专业救援力量）
    → 行业主管
      → 属地
        → 保障（医疗 / 公安 / 宣传 / 民政）
```

> **反例**：`消防、应急、卫健、住建`
> → 应排 **`应急、消防、住建、卫健`**
> （应急综合协调牵头、消防救援主战、住建行业主管、卫健医疗保障）。

## 场景 2　领导小组 / 工作专班

```
组长单位 → 副组长单位 → 成员单位
```

**党委部门在前、政府部门在后**，各自按法定序列；党内序列见「党内法规口径」。

## 场景 3　抄送机关（法定序列）

```
党委 → 人大 → 政府 → 政协 → 纪委监委 → 法院检察院
     → 军事机关 → 人民团体 → 其他
```

> **不得按发文机关熟悉度或词频排序；党委机关列政府机关之前。**

## 场景 4　联合行文

主办机关列首，其余按行政层级与部门序列；
联合发文并列机关标志 + 主办发文字号（**G1 格式域**）。

## 场景 5　责任分工

```
牵头单位 → 配合单位
```

「牵头 / 配合」须**显式标注**，禁止混列掩盖主责。

## 场景 6　表彰 / 批评名单

| 对象 | 排序 |
|---|---|
| **单位** | 级别 → 类别 → 笔画 |
| **个人** | 职务 → 同职务按姓氏笔画；不确定标 `[待确认]` |

## 场景 7　领导同志排名

严格按**现行职务序列**；
跨系统（党委 / 政府 / 人大 / 政协）并列时依政治位阶与党内序列；
**序列不确定一律升提问硬停车，禁止推断。**

## 党内法规口径（党委序列 · 党组关系）

> 党内排序依《中国共产党地方委员会工作条例》《中国共产党党组工作条例》
> 及本单位「三定」方案为准；
> 本节省略具体名单，只定**次序原则**，不确定标 `[待确认]`。

### 1. 党委工作机关序列（一般次序）

```
纪委 → 党委办公厅（室）→ 党委组织部 → 党委宣传部 → 党委统战部
     → 党委政法委 → 党委政策研究室 → 党委机构编制委员会办公室
       → 其他党委工作机关
```

跨部门并列时**党委工作机关列政府工作部门之前**。

### 2. 党委 vs 政府

党委机关列政府机关之前
（抄送、并列枚举、行文主送**均同此原则**）。

### 3. 党组关系

党组在本单位发挥**领导作用**；
党组成员排名依**党内职务与任职顺序**，不以行政职务简单对应；
党组与行政领导班子并列枚举时，**党组在前**。

### 4. 党组会 vs 行政办公会

决策事项分属不同会议层级，并列表述时**先党组会、后行政办公会**；
不得混为一谈或**以行政会议顶替党组决策**。

### 5. 党的工作机关 vs 政府部门联合部署

牵头方依「归口领导」原则定——
党委口工作由对应党委工作机关牵头，政府口工作由主管部门牵头，
**跨口由党委办公部门统筹**。

## 触发与归属

| 环节 | 责任方 |
|---|---|
| **触发器** | 正文预计出现 ≥3 个并列行政主体 → **成文 Pro 由文择体执行**（产出《主体排序表》（顺序 + 排序依据）回填 D-Card D6）；**成文 Flash 与咨询档文择体未编入，由主理人执行并标 `[主理人研判]`** |
| **未编入时** | 主理人依本库研判并标 `[主理人研判]` |
| **终审** | 骆准绳 G2「主体排序合规」子项，命中即 **E8 硬退回** |
| **落写** | 辞达意**严格沿用排序表顺序，不得自行改序**（有异议回传文择体 / 主理人） |
| **取证硬标准** | **排序依据 1 行随附 + 领导名次不推断**，为人工取证标准 |
