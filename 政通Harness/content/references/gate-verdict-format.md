# 门禁取证输出契约（GATING 阶段唯一格式）

> **只在本阶段装载**：过门禁时用，平时写作阶段不读。

## 你要输出什么

你被指派了若干道门禁。**本轮只能调用 `gate.report` 工具报告结论，不要输出自由文本**。

对每道门禁，调用一次 `gate.report` 工具，参数如下：

| 参数 | 说明 | 必填 |
|---|---|---|
| `gate_id` | 门禁编号，如 `G1` | 是 |
| `conclusion` | `通过` 或 `退回`。**只有这两个值** | 是 |
| `evidence` | 你据以判断的**正文原句或具体位置** | 是 |
| `reason` | 退回原因，说清缺什么 | 退回时填 |

```
gate.report(gate_id="G1", conclusion="通过", evidence="正文首句「……」已按 GB/T 9704 规范")
gate.report(gate_id="G4", conclusion="退回", evidence="第 3 段出现「赋能抓手」", reason="AI 味表述")
```

## 五条铁律

1. **一门一调用，道道带门禁号。** 漏掉某道 = 该门禁无证据。
   程序按「你交了几道」核对，缺席即判无证据——不是判通过，是判「没查」。

2. **证据必须是可定位的原句。**
   「已核对全文，格式合规」这种**不算证据**——它无法被复核，等于没查。
   要写你实际看到的那一句，或它在第几段。

3. **没查就说没查，别猜。**
   需要外部依据（政策原文、法规）而手上没有的，把结论写 `退回`，
   原因写「缺 XX 依据」，**不要**凭印象给一个看似合理的通过。

4. **不写门禁没给你的内容。**
   只对你被指派的门禁作答。派给你 G1/G2 就只答这两道。

5. **先答格式，再答内容。**
   工具参数名和类型就是契约，复核时先看结论对不对，再看依据是什么。

**不调用 `gate.report` 工具、或参数不完整，视为未提交，该门禁判为无证据（E041）。**

## 判读方式

程序从 `tool_calls` 里提取 `gate.report` 的调用参数，直接读取 `gate_id` / `conclusion` / `evidence` / `reason`。

写得漂亮但没调用工具，等于没交。
